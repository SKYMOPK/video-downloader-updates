# 驗證紀錄與交付缺口

更新日期：2026-11-09。此文件區分功能與證據，不代表所有 Windows 環境均已驗收。

## 0.2.0 整個 App 更新

- 固定測試 100 項通過。新增正式版版本比較、來源綁定、下載大小與 SHA256、HTTPS 重新導向限制、ZIP 路徑與完整清單驗證、使用者檔案保留、任務交接等待與失敗回復。
- 真實 Windows EXE 驗收：在隔離資料目錄，將 0.2.0 完整更新為本機驗收用的 0.2.1 身分，實際啟動新版並收到健康確認；再使用刻意損壞的 0.2.2 啟動檔，確認回復 0.2.1 並重新啟動。這兩個未來版本只是本機驗收資料，不是公開發布版本。
- 設定與 App 目錄內自建的繁體中文文件均保留。證據：`evidence/app-update-integration.json`。
- 真實 QML 視窗驗證紅點、提示視窗、設定與關閉同版本重複提示；未來版本的 UI 資料明確標示為驗收用。證據：`evidence/app-update-ui.json`，沒有 QML 警告。
- 完整更新初次實測發現 Windows 暫存路徑較長導致解壓失敗；補上長路徑處理，並移除無需隨 App 發布的 Qt 建置中間檔後，重新驗收通過。
- 沿用本機 Windows 11 驗證環境；尚未完成乾淨 Windows 10／11 VM、突然斷電及所有防毒產品的相容性測試。更新驗證採固定 GitHub 來源的 HTTPS 與 SHA256，未提供獨立開發者簽章。

## 畫質選單與網址輸入修正

- 固定測試 64 項通過；新增同畫質編碼合併、59.94／60 fps 分組、保留 30／60 fps 選項與切換容器後保持畫質的驗證。
- 真實 QML 視窗中，以 Qt 鍵盤事件測試 Ctrl+V、自動解析及持續輸入；介面重新整理不再把輸入中的文字還原。
- 右鍵選單貼上動作通過。使用先前保存的真實來源資訊確認選單包含 4K、1080p 等 60 fps 選項。證據：`evidence/input-acceptance.json` 與 `evidence/quality-simplified.png`。這次介面測試不額外下載影片。

## 已取得證據

- 固定測試：涵蓋網址、真實格式規劃、輸出相容性、檔名、原子保存、同名不覆蓋、錯誤重試、程序樹取消、設定、任務恢復、轉碼序列化及更新失敗回復。完整結果見原始碼專案 `evidence/pytest.txt`。
- 實際 FFmpeg／FFprobe：自製 2 秒影音素材驗證 MP4、MKV、H.264 重新編碼、M4A、MP3、Opus、WAV，並完整解碼檢查輸出。
- 真實 YouTube 下載：Blender 官方 Big Buck Bunny 來源，解析資訊明確標示 Creative Commons Attribution。完成整部 360p 30 FPS MP4 下載、影音合併、FFprobe 驗證，以及完整來源音訊轉 MP3。這是同一個來源的不同操作，不計為多個不同來源。
- 真實 QML 整合流程：解析 → 規格選擇 → 影片與音訊兩項佇列 → 取消第三項等待任務 → 兩項完成及輸出驗證；實際狀態截圖與紀錄在 `evidence/ui-acceptance.json`。
- 線上解析矩陣：25 個不同來源公開資訊中，24 個明確標示 Creative Commons 的樣本成功解析；另外 1 個未取得相同授權標示，不計入授權樣本。含官方影片、Shorts 及長篇會議內容。此調查只解析、不下載所有來源，不能推算廣泛下載成功率。完整紀錄在 `evidence/compatibility.json`。
- Qt 有效 DPR 1.0、1.25、1.5 及 900 × 640 小視窗的啟動截圖，對應測試無 QML 警告。125% 是本機實際系統縮放；其餘以 Qt 官方測試方式調整，並非切換 Windows 全域顯示設定。
- Windows 原生視窗：透過 computer-use 檢查來源解析畫面、影片／音訊切換、設定頁及原生標題列。另用 Qt 元件測試產生畫面證據。
- 初期可攜封裝版已實際啟動。發現並修正與宿主 Poppler ICU 相關的 DLL 相容問題；後續建置隔離 PATH。

## 安裝版追加驗證

- 本機系統：Windows 11 家用版，組建 26200，並非乾淨虛擬機。
- 固定測試最終 62 項通過；包含保留成果改存位置時不重新下載、錯誤 FPS／解析度／容器不得標記完成，以及到期清理不刪除非本工具檔案。
- 實際安裝版從 UI 解析及下載同一授權來源的完整 1080p／60 FPS H.264 + AAC MP4，輸出約 275.8 MiB。
- 首輪測試腳本在兩分鐘時限到達後停止 App；任務正確取消並保留暫存。延長測試時限後重開，透過 UI 按重試接續完成。這不是額外來源樣本，也不把中斷的首輪算為成功下載。
- 1080p 成果經 FFprobe 確認 1920 × 1080、約 60 FPS、H.264 與 AAC，影片／音訊起點均為 0，時長差約 58ms；在 0、300、630 秒各解碼 3 秒均無錯誤。
- 實際點選「開啟檔案」後，Windows 媒體播放器可開啟並顯示影片。這項觀察不等同於完整 10 分鐘影音同步人工驗收。
- 官方核心檢查、下載、SHA256 驗證、啟動檢查、新核心配隨附 Deno 的實際來源解析、回復隨附核心均已執行，見 `evidence/update-acceptance.json`。
- 本機安裝、啟動、相同版本重新安裝及解除安裝流程有 JSON 與安裝紀錄。相同版本重裝不是跨版本資料遷移驗證。結果見 `evidence/package-acceptance.json`。

資源量測：兩輪安裝測試的短窗閒置平均約 0.99% 與 1.42% 單一邏輯核心，主程序及子程序峰值 RSS 約 202～213 MiB，安裝後約 492 MiB，安裝包約 175 MiB。第二輪沒有穩定低於初始 1% CPU 目標，因此另做針對性檢查：原始碼版兩段 15 秒量測為約 0.52% 與 0.10%，期間沒有連續畫面交換，未觀察到持續重繪迴圈。這些短窗與不同狀態的樣本不足以保證長時間效能，保留進一步量測的缺口，不提高預算來掩蓋差異。

初始化、排程與系統環境會影響數字；完整每輪數據見 `evidence/package-interruption.json`、`evidence/package-acceptance.json` 與 `evidence/performance-probe.json`。尚未對冷啟動到可操作時間取得可比較的精確數據，不把固定截圖等待時間當作啟動時間。
